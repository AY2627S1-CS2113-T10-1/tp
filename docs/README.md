# ScheduleFlow

[![ScheduleFlow terminal showing a saved Saturday schedule: task T1 from 08:00 to 08:30, task T2 from 08:30 to 09:30, a break until 10:00, and free time until 22:00.](images/Ui.png)](images/Ui.png)

An example saved schedule. Select the image to view it at full size.

**ScheduleFlow is a command-line application for university students planning coursework around classes and other commitments.** Track remaining work, record progress, and generate study schedules before your deadlines. Successful changes and generated plans save automatically on your computer.

- To start using ScheduleFlow, follow the **[Quick start](QuickStart.md)**. You will need Java 25.
- For commands, examples, and troubleshooting, see the **[User Guide](UserGuide.md)**. For exact command formats, use its [command summary](UserGuide.md#command-summary).
- To develop ScheduleFlow, start with the **[Developer Guide](DeveloperGuide.md)**.
